Settings for where captured manual pages are written.
Relative to your browser's Downloads directory. Use / for sub-levels, e.g. cars/gs450h. Leave blank to save at the Downloads root.
Overwrite existing files Re-saving the same page replaces it instead of creating adjustment (1).html. Recommended.
Put each vehicle in its own folder Adds a gs450h_2007 level at the top. Turn this on if you look up manuals for more than one car.
Show a message when something goes wrong A desktop notification explaining what happened, instead of just a red badge on the icon.
Ask where to save each time Opens the system file picker so you can save anywhere on disk, outside Downloads. Slow if you are saving many pages in a row.

Already-saved index

The toolbar icon shows a green ✓ when the page you are reading has already been saved. Pages saved before this feature existed are not in the index yet — rebuild it from your archive and load it here:
node build-index.js ~/Downloads/TIS
Why can't I pick any folder directly?
Chrome extensions can only write inside the browser's Downloads directory — absolute paths are rejected by the browser, not by this extension. Three ways around it: (1) set a memorable sub-folder above; (2) tick "Ask where to save each time"; or (3) change Chrome's own download location in chrome://settings/downloads, which affects all downloads.
